# Guider

Läs guiderna när du behöver dem. De fungerar som uppslagsbok, både under
övningarna och när du arbetar på egen hand.

## Läsordning

| Nr | Guide | Handlar om | Används i |
|---|---|---|---|
| 1 | [Variabler och datatyper](variabler-och-datatyper.md) | `int`, `double`, `bool`, `string`, att räkna, heltalsdivision | Alla övningar |
| 2 | [Villkor, loopar och arrayer](villkor-och-loopar.md) | `if`, `for`, `while`, `foreach`, arrayer, fyra loopmönster | 01, 02 |
| 3 | [Metoder](metoder.md) | Parametrar, returvärden, att anropa metoder | 01, 02 |
| 4 | [Testkör din kod själv](testkora.md) | Provkör-projekt, utskrifter, debuggern, att läsa testfel | Alla övningar |
| 5 | [Filstrukturen i C#](filstruktur.md) | Solution, projekt, kodfiler, program eller bibliotek | 03 |
| 6 | [Recept: skapa projekt](skapa-projekt.md) | Skapa eget bibliotek och program, vanliga fel | 03 och egna projekt |

## Varje guide slutar med "Prova själv"

Där finns små uppgifter som du gör i ett **Provkör-projekt**. De rättas
inte. De finns för att du ska prova, gissa och se vad som händer.
